01 / Useful places to start

Infrastructure for the full development lifecycle.

Agent orchestration
Route scoped tasks to agents with repository instructions, isolated workspaces, and bounded tool access. Capture changes, test evidence, and exceptions for engineering review.
Engineering context
Connect architecture decisions, code, product requirements, and operating documentation. Define source ownership, access boundaries, and how context stays current.
Continuous delivery
Integrate automated tests, code review, security checks, and CI/CD. Define release approval, environment promotion, production verification, and rollback procedures.
Evaluation and observability
Track workflow completion, failure modes, review effort, and model usage. Evaluate quality on representative tasks before widening automation.

02 / Illustrative example · Not client work

From a reported issue to a reviewed change.

  1. Context

    Make the task understandable.

    Start with the reported problem, relevant product notes, and a clear description of the expected behavior.

  2. Preparation

    Use AI to help do the work.

    Investigate the issue, prepare a proposed change, and run the relevant checks. Record uncertainties and test results.

  3. Review

    Check before release.

    A person reviews the change and its evidence. The release follows the company’s agreed process, with a way to check the live result.

03 / What I put in place

An operable engineering system.

A defined workflow
Agree the task, inputs, expected result, and where a person makes decisions. Use simpler automation where it fits.
Connected information and tools
Configure the selected tools and access, organize the relevant knowledge, and document the setup.
Checks that fit the task
Try representative work, including missing context and failure cases. Review output quality, running costs, and the effort needed to oversee it.
Operational handoff and improvement
Validate the runbooks with your engineers. Establish ownership, escalation paths, and a maintenance plan; scope continued implementation and optimization as an ongoing partnership.

AI can support the development process and everyday business work. Technical judgment, review, and responsibility remain part of the system.
