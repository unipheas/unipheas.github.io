How I Work

Practical AI-assisted delivery.

I use AI the same way I use any other engineering tool: inside a process that still cares about review, traceability, and production quality.

The internal framework I use is called CADE: Continuous Autonomous Development Environment. In practice, that means structured planning, implementation, code review, and testing agents working inside a governed workflow, with human sign-off at the points that matter.

The toolchain changes by team, but usually includes Claude Code, OpenAI Codex, workflow automation, MCP servers, and custom task-specific tooling. I use this on shipped products and client work. Infinite Miner was built end-to-end with this approach, and I apply the same discipline in consulting and team environments where quality and auditability matter.

Used well, this does not replace engineers. It removes drag, tightens review loops, and lets a small team cover more ground without lowering the bar.
