Tommy’s / Mobile engineering

POP & FLEX

Built both products from scratch.
Mobile development leadership.

Two iPad applications for two different parts of a car wash. POP handles exterior-wash customer transactions; FLEX supports interior detail belts. I built both from scratch, with work spanning Swift, UIKit, RxSwift, and SwiftUI. For FLEX, I packaged the API client as a reusable Swift Package Manager module.

Today I lead two direct reports and one contractor at Tommy’s; previously I led four contractors. My broader mobile work includes feature development, cleanup, and bug fixes on the React Native customer app, where I contributed as part of the team.

Product implementation and ongoing mobile leadership, from transaction flows to shared application infrastructure.

  • Swift / SwiftUI
  • UIKit / RxSwift
  • Swift Package Manager
  • React Native

Let’s Ride / Development operations

CADE

System built from the ground up.
Technical Consultant; previously Fractional CTO.

I built CADE to connect AI-assisted development with the work of running a product. The system connects Sentry incidents, agent-driven fixes and pull requests, CI/CD, and AWS monitoring and maintenance.

I also enabled the owner to develop app changes using AI and simulator feedback. Changes move through automated builds, tests, and staging deployments. Production releases require approval, with deployment verification and recovery procedures supporting the release process.

Independent product / iOS

MotoCare

Design & development.
Motorcycle maintenance log.

A focused app for keeping track of motorcycle maintenance. I built MotoCare in SwiftUI so riders could track service by date or odometer reading and receive reminders when work is due.

The core workflow covers recurring needs such as oil changes and tire replacements: record the service, keep its history, and know when to do it again.

  • SwiftUI
  • iOS
  • Service reminders
